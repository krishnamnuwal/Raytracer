# Raytracer 
This project was developed as part of the Spring Camp organized by the Programming Club at IIT Kanpur. My main goal was to understand the actual math and physics behind how light behaves, interacts with objects, and renders in a 3D environment.

* **Rust:** For the application logic.
* **WGSL:** Used to write the shaders
* 
Working on this project was a great way to explore:
* The  maths of 3D rendering (like vector, rays, and sphere intersections).
* The physics of lighting, including how materials reflect and absorb light.
* How to use the GPU for parallel processing to speed up rendering times.
